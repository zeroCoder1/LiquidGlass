# Contributing

Thanks for your interest in improving Liquid Glass.

## Layout

```
src/        the library (ESM source of truth)
types/      hand-written TypeScript definitions
dist/       built bundles (generated by npm run build, committed for CDN use)
test/       Node test-runner tests (pure logic + build integrity + types)
build.mjs   esbuild build script
*.html      demo site (also served at the GitHub Pages URL)
```

## Develop

```bash
npm install
npm start            # serve the repo at http://localhost:5173
npm run build        # rebuild dist/
npm test             # run the test suite
npm run typecheck    # validate the public .d.ts against real usage
```

Open `http://localhost:5173/check.html` for the capability diagnostics, and the
other `*.html` pages for the demos.

## Before opening a PR

- `npm run build && npm test && npm run typecheck` all pass.
- Commit the rebuilt `dist/` if you changed `src/` (CI checks it is up to date).
- Keep changes focused; match the surrounding code style.

## Releasing

1. Update the version in `package.json` and add a `CHANGELOG.md` entry.
2. `npm run build && npm test`.
3. `npm publish` (runs the build + tests via `prepublishOnly`).
